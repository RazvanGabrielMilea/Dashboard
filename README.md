# UK Road Accidents Dashboard (Streamlit)

Interactive dashboard for UK road accident analytics:
- Overview KPIs
- Trends & seasonality
- Hotspot map clustering
- Factors & severity
- Explorer (filter + export)
- ML & Insights (correlations + what-if scenarios)
